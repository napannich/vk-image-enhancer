Отзыв куратора о прохождении производственной (проектно-технологической) практики

Обучающийся: Напалков Андрей Образовательная программа: магистратура, Университет ИТМО Период практики: 16.02.2026 — 15.04.2026 (6 з.е.) База практики: VK Education (ООО «В Контакте») Учебная группа: Уч_П95-11 Проектная задача: «ML-модель для улучшения изображений в браузере»

За время прохождения практики Напалков Андрей выполнил все задачи, предусмотренные индивидуальным планом и техническим заданием проектной задачи VK Education.

Выполненные задачи: - проведён анализ технического задания и зафиксированы функциональные и нефункциональные требования; - спроектирована и реализована архитектура клиентского веб-приложения с ML-инференсом в браузере; - реализован публичный API согласно рекомендациям ТЗ (методы постановки задачи, получения статуса, прерывания, получения результата, а также событие изменения статуса); - обеспечена поддержка всех требуемых форматов (JPG, PNG, HEIC, BMP) и обработка изображений до 15 Мпикс; - реализованы механизмы надёжности: жёсткий timeout 30 с, graceful fallback при недоступности ML-runtime; - приложение развёрнуто на публичном хостинге и протестировано во всех массовых браузерах.

Освоенные технологии: ONNX Runtime Web (WASM), Real-ESRGAN, TensorFlow.js, Web Workers, Transferable Objects, Canvas API, OffscreenCanvas, TypeScript (strict), tile-based inference, квантизация ML-моделей, GitHub Pages.

Архитектурные и инженерные решения: - tile-based inference (тайлы 128×128 с padding 8 пикселей) для фиксированного бюджета памяти независимо от размера входа; - inline Web Worker через Blob URL, обеспечивающий работу приложения с любого статического хостинга и протокола file://; - двухуровневая стратегия обработки — ONNX-инференс как основной путь и алгоритмический пайплайн (auto-levels по перцентилям p5/p95, Unsharp Mask, Lanczos 2x апскейл) как fallback; - сохранение альфа-канала для PNG-изображений; - централизованный менеджер задач (TaskManager) с подпиской на события и управлением очередью.

Объём разработки: - ~1700 строк кода в главном модуле (UI + TaskManager + Web Worker); - ~800 строк типизированного TypeScript-кода в модульной сборке (src/); - итоговый объём бандла ~5 МБ (при лимите 10 МБ); - 8 содержательных коммитов с последовательной историей развития решения.

Метрики производительности (результат апробации): - среднее время обработки изображения 5 Мпк: 3–7 секунд (в зависимости от браузера и CPU); - все тестовые сценарии укладываются в ограничение 30 с; - поддержка четырёх форматов подтверждена ручным тестированием.

Проектная задача сдана в полном объёме, решение размещено на публичном хостинге: https://napannich.github.io/vk-image-enhancer
