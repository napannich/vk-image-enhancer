## Слайд 2. Актуальность

- Браузерный ML-инференс снимает нагрузку с серверов и обеспечивает приватность (изображение не покидает устройство)
- Классическая ML-пайплайн обработки пользовательского контента дорога на GPU-серверах и плохо масштабируется
- WASM + ONNX Runtime Web позволяют запускать достаточно мощные модели прямо в браузере
- Практическая задача VK Education: улучшение качества изображений (яркость / контрастность / цветность) через ML-модель в браузере — реальный enterprise-кейс

## Слайд 3. Цель и задачи

**Цель:** разработать кросс-браузерное приложение, улучшающее изображения через ML-модель в браузере, с жёсткими ограничениями по времени и объёму кода.

**Задачи:**
1. Анализ ТЗ, выбор ML-модели и стека
2. Архитектура: UI-поток + Web Worker + ML-runtime
3. Реализация API (submit / status / cancel / result + событие)
4. Поддержка JPG / PNG / HEIC / BMP до 15 Мпк
5. Fallback при недоступности ML-runtime
6. Деплой и кросс-браузерное тестирование

## Слайд 6. Решение задач — ML

- **Real-ESRGAN x4** (ONNX, 4.6 МБ) — super-resolution модель
- **ONNX Runtime Web (WASM)** подгружается с CDN при первом использовании
- **Tile-based inference** 128×128 + padding 8 — фиксированный бюджет памяти независимо от размера входа
- **Авто-даунскейл до 768 px** перед инференсом → 4× апскейл возвращает целевой размер, укладываясь в 30 с

---

## Слайд 7. Решение задач — UX и надёжность

- **TaskManager** — централизованное управление задачами, очередь, события
- **Hard timeout 30 с** на уровне менеджера: auto-cancel + пересоздание worker-а
- **Graceful fallback**: при недоступности ONNX — алгоритмический пайплайн (histogram → auto-levels p5/p95 → Unsharp → Lanczos)
- **Сохранение PNG в PNG** (альфа-канал)
- **Inline Web Worker** через Blob URL — работает с любого хостинга и `file://`

## Слайд 8. Публичный API

```javascript
// Постановка
const { taskId } = await window.enhancer.submitTask(file, opts);

// Статус
const { status, progress } = window.enhancer.getStatus(taskId);

// Прерывание
const { success } = window.enhancer.cancelTask(taskId);

// Результат
const { blob, url } = window.enhancer.getResult(taskId);

// Событие
window.enhancer.on('statusChange', ({ taskId, status, progress }) => {...});
```

Все четыре метода и событие — ровно как в ТЗ.

## Слайд 11. Связь с треками ОП

**Искусственный интеллект**
- подбор ML-модели под жёсткие ограничения (объём, скорость, качество)

- архитектурная приватность: данные не покидают браузер
- UI скрывает сложность: drag&drop, авто-режим, ручная тонкая настройка
- кросс-браузерная совместимость как забота о реальных пользователях
